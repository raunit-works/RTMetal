RT METAL Coating — Client Finish Review Package
================================================

PACKAGE CONTENTS
----------------
- finish-sample-client-review.html  (portable offline review document)
- images/                          (12 original FIN photographs)
- client-finish-approval.csv       (master approval register, 12 rows, all PENDING)
- README.txt                       (this file)

INSTRUCTIONS
------------
1. Extract the ZIP file to a local folder on your computer.
2. Open finish-sample-client-review.html in any web browser (Chrome, Edge, Firefox, etc.).
3. Review the twelve finish-sample photographs shown in the package.
4. Fill in the relevant approval fields for each sample:
   - Corrected finish name (if the proposed name differs)
   - Confirmed coating process
   - Supported substrate / material
   - Availability confirmation
   - Actually offered by company (PENDING / YES / NO)
   - Image publication permission (PENDING / YES / NO / HOLD — defaults to PENDING)
   - Final review decision (PENDING / APPROVE / REJECT / NEEDS CHANGES — defaults to PENDING)
   - Reviewer name
   - Approval date
   - Remarks
5. Click the "Download Completed Approval CSV" button to export your responses.
6. Return the downloaded CSV file (with any corrections) to the project team.

IMPORTANT NOTES
---------------
- Saving or printing this HTML page alone does NOT save your completed responses.
  You MUST click "Download Completed Approval CSV" and return that CSV file.
- All proposed finish names are tentative visual labels based on filename and
  appearance. They are not verified production capabilities and do not imply any
  coating process (PVD, PU, electroplating, powder coating, etc.).
- No image has been approved for publication. Image publication permission remains
  undecided until you select YES / NO / HOLD for each sample.
- Original photographs are preserved unmodified — no recolouring or visual
  alteration has been applied.
- This package is self-contained: images are stored in the local images/ folder
  and do not depend on the original catalogue directory.
- This document is INTERNAL CLIENT REVIEW — NOT FOR PUBLICATION.

CONTACT
-------
Return the completed CSV to your RT METAL Coating project contact.
